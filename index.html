The Basics

What is a lookup function?

A lookup function answers one simple question: "Find this value in my data, and bring back something related to it." Think of a phone book — you look up a name (what you know) to find a phone number (what you want). Excel lookup functions do exactly that, thousands of times per second.

VLOOKUP — Vertical

Your table grows downward (records in rows). VLOOKUP searches down the first column and returns a value from a column to the right.

Jan Feb Mar
120 135 148
→

HLOOKUP — Horizontal

Your table grows sideways (records in columns). HLOOKUP searches across the first row and returns a value from a row below.

🎯 Rule of thumb

Match the function to your table's shape:

  • V for Vertical data → VLOOKUP
  • H for Horizontal data → HLOOKUP

90% of real-world spreadsheets are vertical — which is why VLOOKUP is the celebrity and HLOOKUP is its lesser-known sibling.

Function №1

VLOOKUP — search down, return across

VLOOKUP scans the first column of a table vertically to find your lookup value, then returns the value from another column in that same row.

Syntax

=VLOOKUP(lookup_value, table_array, col_index_num, [range_lookup])
lookup_value
The value you want to find — e.g. an Employee ID 105.
table_array
The range containing your data. The first column of this range must hold the lookup values.
col_index_num
Which column of the range to return from. 1 = first column of the range, 2 = second, and so on.
range_lookup
FALSE = exact match (use this 95% of the time). TRUE = approximate match (for sorted bands like tax brackets).

📸 Example: look up an employee's department by ID

In cell G2 we type =VLOOKUP(F2, A2:D8, 3, FALSE). The formula bar shows the four color-coded arguments, and the highlights show exactly what each one points to.

  1. Search down. Excel takes the lookup value F2 (= 105) and scans down the first column of A2:D8 — that's column A, the Emp IDs.
  2. Match found. It stops at row 6, where Emp ID 105 lives.
  3. Step across. From that row, it moves to the 3rd column of the range — Department. (The range starts at A, so A=1, B=2, C=3.)
  4. Return it. The last argument FALSE demands an exact match, so Excel confidently drops "Marketing" into G2. ✔

📸 Example 2: approximate match — grading scores

When TRUE is used, VLOOKUP finds the largest value that is still ≤ the lookup value. Perfect for score bands, tax slabs and commission tiers. A score of 78 falls into the 60–79 band → grade C. The lookup column must be sorted ascending.

Function №2

HLOOKUP — search across, return down

HLOOKUP is VLOOKUP's mirror image. It scans the first row of a table horizontally, then returns a value from a row below the match. You use it when your data is laid out sideways — like months running across the top of a report.

Syntax

=HLOOKUP(lookup_value, table_array, row_index_num, [range_lookup])
lookup_value
The value to find in the first row — e.g. the month "Mar".
table_array
The data range. Its first row must hold the lookup values.
row_index_num
Which row of the range to return from. 1 = the header row itself, 2 = the row below it…
range_lookup
FALSE = exact match, TRUE = approximate. Same rules as VLOOKUP.

📸 Example: fetch the East region's March sales

Months run across the top, so VLOOKUP can't help — HLOOKUP is the right tool. In B8 we type =HLOOKUP(B7, B1:F5, 4, FALSE).

  1. Search across. Excel takes B7 (= "Mar") and scans rightward along the first row of B1:F5 — the month headers.
  2. Match found. It stops at column D, where "Mar" sits.
  3. Step down. From that column, it moves to the 4th row of the range — East. (Row 1 = headers, 2 = North, 3 = South, 4 = East.)
  4. Return it. Exact match FALSE confirmed → 16,200 lands in B8. ✔

💡 Notice the one difference: VLOOKUP counts columns after searching down; HLOOKUP counts rows after searching across. Everything else — exact vs approximate match, the #N/A behaviour — works identically.

Side by side

VLOOKUP vs HLOOKUP

VLOOKUP HLOOKUP
Data orientation Vertical — values listed down a column Horizontal — values listed across a row
Excel searches… ↓ down the first column → across the first row
3rd argument counts… columns → col_index_num rows → row_index_num
Returns a value from… a column to the right of the match a row below the match
Typical use Employee lists, product catalogues, any record-per-row table Timetables, month-across reports, matrices
Frequency in the wild ★★★★★ everywhere ★★☆☆☆ occasionally

🧭 Still unsure which to use? Look at where your headers are. Headers in the first row (top) → VLOOKUP. Headers in the first column (left) → HLOOKUP. The letter of the function matches the direction Excel travels to find your value: V travels vertically, H travels horizontally.

Troubleshooting

Common errors & how to fix them

Every Excel user meets these. Here's what each one is really telling you — each with a mini screenshot of the failing formula.

#N/A Value not found

E2
fx
=VLOOKUP(110, A2:C8, 2, FALSE)
A B C D E
1 Emp ID Name Dept Dept:
2 101 Priya HR #N/A
3 102 Rahul IT

Why: Excel searched the whole first column and never found 110.

✔ Fix: check spelling, stray spaces (TRIM), or the ID itself. Show a friendlier message with =IFNA(VLOOKUP(…), "Not found").

#REF! Column index too big

E2
fx
=VLOOKUP(101, A2:C8, 9, FALSE)
A B C D E
1 Emp ID Name Dept Dept:
2 101 Priya HR #REF!
3 102 Rahul IT

Why: The range A2:C8 has only 3 columns, but you asked for column 9.

✔ Fix: count columns within the range, not the worksheet. Valid here: 1–3.

#VALUE! Index below 1

E2
fx
=VLOOKUP(101, A2:C8, 0, FALSE)
A B C D E
1 Emp ID Name Dept Dept:
2 101 Priya HR #VALUE!
3 102 Rahul IT

Why: The column/row index must be at least 1 — 0 (or a negative number) is meaningless.

✔ Fix: set the index to a whole number ≥ 1.

#NAME? Misspelled function

E2
fx
=VLOKUP(101, A2:C8, 2, FALSE)
A B C D E
1 Emp ID Name Dept Dept:
2 101 Priya HR #NAME?
3 102 Rahul IT

Why: VLOKUP isn't a function — one scrambled letter is enough. Excel also throws this when text like Mar is typed without quotes.

✔ Fix: fix the spelling; wrap text values in quotes: "Mar".

#N/A Text vs number trap

E2
fx
=VLOOKUP("101", A2:C8, 2, FALSE)
A B C D E
1 Emp ID Name Dept Dept:
2 101 Priya HR #N/A
3 102 Rahul IT

Why: "101" in quotes is text; the table stores the number 101. They look identical but don't match.

✔ Fix: match the types — =VLOOKUP(VALUE("101"), …) or re-enter the ID as a number.

⚠ No error — wrong answer! The sneakiest bug

E2
fx
=VLOOKUP(105, A2:C8, 2)
A B C D E
1 Emp ID Name Dept Dept:
2 101 Priya HR Priya ✗
3 102 Rahul IT

Why: The 4th argument was omitted, so Excel defaulted to TRUE (approximate). On unsorted IDs it silently guesses — returning Priya's name for ID 105. No error, just wrong data.

✔ Fix: always type FALSE unless you specifically need approximate matching.

🛡️ Pro habits: lock your ranges with dollar signs ($A$2:$D$8, press F4) before filling formulas down · wrap with IFNA for clean reports · remember VLOOKUP can never look left — its first column must contain the lookup values.

Looking ahead

The modern successor: XLOOKUP

If you have Excel 365 or Excel 2021+, meet XLOOKUP — it fixes every historic annoyance of V/HLOOKUP:

=XLOOKUP(105, A2:A8, C2:C8, "Not found")
  • 🔍 Looks in any direction — left, right, up, down (no more "can't look left").
  • 🎯 No column counting — you point directly at the return range C2:C8.
  • 🛡️ Exact match is the default — the silent-wrong-answer bug disappears.
  • 💬 A built-in "if not found" message replaces IFNA wrappers.

📚 VLOOKUP and HLOOKUP remain essential — older workbooks, interviews and exams are full of them. Learn these two first, and XLOOKUP will feel like a superpower you've already earned.
